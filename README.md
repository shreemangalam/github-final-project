# Simple Interest Calculator

## Description
This repository contains a simple bash script (`simple-interest.sh`) that computes simple interest based on user input. It was created as part of the Introduction to Git and GitHub final project.

## How it Works
The script calculates simple interest using the standard formula:
`Simple Interest = (Principal * Rate * Time) / 100`
